# Shopbujo Hatto (ସବୁଜ ହାଟ)

A local Indian grocery e-commerce storefront for fresh vegetables, leafy greens, and seasonal fruits, built with **Next.js App Router**, **TypeScript**, and **Tailwind CSS**.

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) with your browser.

### 3. Build & Production
```bash
npm run build
npm run start
```

### 4. Code Quality & Testing
```bash
npm run lint    # Strict TypeScript verification
npm run test    # Automated unit tests for catalogue, pricing & validation
```
